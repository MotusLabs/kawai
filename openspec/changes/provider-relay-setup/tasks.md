# Tasks

One PR per section, one dev each, in order: 1–4 are independent of each
other; 5 needs 1–2; 6 needs 1–3; 7 needs 6; 8 needs 3; 9 (integration)
needs all. Planning artifacts (this change) precede all of them; the
`openrouter-provider` change archives before this one (design D11) — land
its master state first and re-check the REMOVED block's text at rebase.
Every task cites oracle ids from design.md (L#, D9 rows, P#, D12) and the
delta-spec scenarios it implements; a test that covers a spec scenario
names it with `// @covers`. Security invariants (P1, P7) apply to every
task: no credential value in SQLite, backups, logs, wire logs, client
payloads, or agent env beyond the composed token/header path; example
hosts only in tests and fixtures.
