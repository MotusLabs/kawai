# Tasks

One change, six ordered groups, one serialized writer (design "Execution
checkpoints"). A group starts only after the previous group's checkpoint is
recorded. Every Verify bullet cites oracle ids from design.md "Acceptance
oracles" and names the mutant it must kill; each table is committed
verbatim as a table-driven test with the code it covers; a test covering a
spec scenario names it with `// @covers`. Every test and rehearsal uses
temp or disposable homes, a private tmux socket, and fixture service
directories: never the owner's live data, tmux server, or units. Never run
`bun run test:e2e`; e2e runs only through the private CI fixture path
(a fixture-gated spec listed by `scripts/e2e-fixture-specs.ts`, run by the
CI fixture step or in a disposable checkout with its own database and a
spare port using CI's fixture setup). The old-to-new task map is in
design.md "Source task map".
