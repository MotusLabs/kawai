# Codex app-server protocol types

Generated by `codex app-server generate-ts --experimental` (ts-rs) from the
installed codex-cli whose version `VERSION` records. Do not edit by hand.

Regenerate (scratch `CODEX_HOME` so no operator configuration is read):

```
CODEX_HOME=$(mktemp -d) codex app-server generate-ts \
  --out src/server/chat/codex/protocol
```

then update `VERSION` and the baseline constant in
`src/server/chat/codex/codexExecutable.ts` together, and rerun the driver's
fake-server tests plus `scripts/codex-smoke.ts` (design D3). Only the types
the driver imports are referenced; the rest of the folder is inert. Lint
ignores this folder (see the `lint` script).
